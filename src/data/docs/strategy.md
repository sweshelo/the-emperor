# CODE OF JOKER - 戦略ガイド

## 1. 基本方針

### テンポ

CPを効率的に使用し、盤面優位を築く。

### カードアドバンテージ

手札枚数を維持する。オーバーライドはドローソースとしても機能する。

### ライフ管理

攻守のバランスを判断する。残りラウンドとLP差を常に意識する。

### 情報収集

相手の捨札・消滅札を確認し、デッキ構成と残りカードを推測する。

---

## 2. ラウンド終盤の判断

- 同点時は**後攻有利**（後攻が勝利）
- 先攻はLP1点リードを維持する必要がある
- 最終ラウンドに向けた逆算が重要

---

## 3. 相手トリガーゾーンの読み

相手のトリガーゾーンは**枚数と属性のみ**が見える。

- 属性から発動可能なインターセプトを推測
- 相手の捨札から使用済みカードを確認し、残り候補を絞る
